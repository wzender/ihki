## 1. איך קוראים את התעתיק

| בתעתיק | איך הוגים | דוגמה |
|---|---|---|
| ח | ח לועית: מכווצים את הגרון ונושפים, בלי גירוד | חַמַּאם (שירותים) |
| ח' | ח עברית רגילה | ח'ֵיר (טוב) |
| ע | ע לועית עם קול | סַאעַה (שעה) |
| ע' | ר עברית רגילה (גרונית) | בַּשְתְע'ִל (אני עובד) |
| ר | ר מתגלגלת בקצה הלשון | כְּתִיר (הרבה) |
| צ | ס מודגשת, **לא** ts | צַבַּאח (בוקר) |
| ט | ת מודגשת | מַחַטַּה (תחנה) |
| ד' | ד מודגשת | בַּעְד' (אחד את השני) |
| ט' | ז מודגשת | ט'ֻהְר (צהריים) |
| ק | לפי הניב: עצירה בגרון (עיר) או כּ (כפר). ראו חלק 2 | אַהְוֶה / כַּהְוֶה (קפה) |
| ג' | כמו ב'ג'ינס', או ז' | פִנְג'אן (כוס קפה) |
| צ' | כמו ב'צ'יפס'. רק בניב הכפרי, במקום כּ | צ'ַלְבּ (כלב, בכפר) |
| ת' | th כמו ב־think. רק בניב הכפרי | ת'לַאת'ֶה (שלוש, בכפר) |
| ד״ | th כמו ב־this. רק בניב הכפרי | ד״ַהַבּ (זהב, בכפר) |
| ו | w, אף פעם לא v | וֵין (איפה) |
| ב | b, אף פעם לא v, גם בסוף מילה | שוֹבּ (חם) |
| פ | f, אף פעם לא p | פַאהֵם (מבין) |
| ה | נשיפה רכה, תמיד נשמעת | אַהְוֶה (קפה) |
| א | עצירה קצרה בגרון | אַהְלַא (שלום) |
| אַא, ִי, וּ | תנועה ארוכה: מחזיקים בערך כפול | כְּתִיר = ktiir |
| ְ (שווא) | בלי תנועה: שני העיצורים צמודים. בתחילת משפט קשה להגות שווא, ולכן מותר שיישמע כמו e קצרה (צירה) | כְּתִיר = ktiir, ובתחילת משפט גם ketiir |
| ֻ (קובוץ) | u קצרה אבל ברורה ומלאה, אף פעם לא נבלעת לשווא | מֻחַאמִי = muħaami, לא mħaami |
| ּ (דגש) | עיצור כפול: מחזיקים אותו | חַמַּאם = ħam-maam |

## 2. שני ניבים, שניהם נכונים

בערבית הפלסטינית יש שני ניבים עיקריים: **עירוני** (ירושלים, יפו, חיפה, שכם, רמאללה) ו**כפרי** (פַלַּאחִי, בכפרי הגדה והגליל). ההבדל העיקרי ביניהם הוא בחמש אותיות. האפליקציה מקבלת את שתי ההגיות, והמורה מחליט איזו מהן ללמד.

| אות | עירוני | כפרי | דוגמה: עיר / כפר |
|---|---|---|---|
| ק | עצירה בגרון (א) | כּ | אַהְוֶה / כַּהְוֶה (קפה) |
| כּ | כּ | בכפרים רבים צ' | כַּלְבּ / צ'ַלְבּ (כלב) |
| ת' | ת (ובמילים ספרותיות ס) | ת' (th כמו think) | תְלַאתֶה / ת'לַאת'ֶה (שלוש) |
| ד״ | ד (ובמילים ספרותיות ז) | ד״ (th כמו this) | דַהַבּ / ד״ַהַבּ (זהב) |
| ט' | ד' או ט' מודגשת | ט' מודגשת (th מודגשת) | ד'ֻהְר / ט'ֻהְר (צהריים) |

**דוגמה שמראה למה זה חשוב:** בכפר, קַלְבּ (לב) נהגה כַּלְבּ, וכַּלְבּ (כלב) נהגה צ'ַלְבּ. בעיר, אותן שתי מילים נהגות אַלְבּ (לב) וכַּלְבּ (כלב). כלומר "כַּלְבּ" פירושו לב בכפר וכלב בעיר. האפליקציה בודקת לפי המשפט שביקשו מכם לומר, ולכן שתי ההגיות יתקבלו במקומן.

**המלצה:** בחרו ניב אחד והיצמדו אליו. האפליקציה לא תוריד ציון על ערבוב, אבל דובר ילידי לא מערבב.

## 3. כללים שהאפליקציה בודקת

הכללים מסודרים לפי כמה הטעות עולה לכם: **משנה משמעות** קודם, אחריו **מבטא עברי חזק**, ובסוף **דיוק**.

### 3.1 ח לועית · משנה משמעות
- **למה זה קשה:** בעברית המודרנית ח ו־כ נהגות אותו דבר, בחיכוך של גב הלשון בחך הרך. בערבית זה צליל אחר (ח'), ושתי המילים בזוג שלמטה שונות לגמרי.
- **מה עושים:** גב הלשון לא נוגע בחך. מכווצים את שרירי הלוע, נמוך בגרון, ונושפים. הצליל יבש ונקי, בלי גירוד. אם מרגישים רטט או חיכוך מאחור בפה, יצאה ח' עברית.
- **זוג מינימלי:** חַאל (מצב) ≠ ח'ַאל (דוד מצד האם)
- **דוגמאות:** חַמַּאם (שירותים), מְנִיח (טוב), תִחְכִּי (לדבר)

```yaml
id: pharyngeal_h
title: ח לועית
arabic: ح
checks:
  - {target: ħ, heard: [χ, x], severity: 3, feedback: "נהגתה כמו ח עברית (חיכוך בחך). ח ערבית נוצרת בלוע: כווצו את הגרון ונשפו, בלי גירוד."}
  - {target: ħ, heard: [h, ɦ], severity: 2, feedback: "נהגתה רכה מדי, כמו ה. צריך יותר כיווץ בלוע: לחישה חזקה מגרון צר."}
  - {target: ħ, heard: ["_"], severity: 2, feedback: "לא נשמעה. ח היא עיצור מלא, גם באמצע מילה."}
```

### 3.2 ע לועית · משנה משמעות
- **למה זה קשה:** בעברית הישראלית ע נהגית כמו א, או נבלעת לגמרי.
- **מה עושים:** אותו כיווץ לוע של ח, אבל עם קול, כלומר מיתרי הקול רוטטים. אומרים 'אַ' כשהגרון מכווץ, בלי לסגור אותו לגמרי כמו ב־א.
- **זוג מינימלי:** עַלַם (דגל) ≠ אַלַם (כאב)
- **דוגמאות:** סַאעַה (שעה), בְּתִעְמַל (אתה עושה), אִלְעַרַבִּי (הערבי)

```yaml
id: ayin
title: ע לועית
arabic: ع
checks:
  - {target: ʕ, heard: [ʔ], severity: 3, feedback: "נהגתה כמו א (סגירה של הגרון). ע לא סוגרת את הגרון, היא מכווצת אותו, עם קול."}
  - {target: ʕ, heard: ["_", a, aː], severity: 3, feedback: "נבלעה. ע נהגית תמיד, גם באמצע מילה."}
```

### 3.3 עיצורים מודגשים: צ, ט, ד', ט' · מבטא חזק
- **למה זה קשה:** בעברית אין עיצורים מודגשים: ט עברית זהה ל־ת. ו־צ עברית היא ts, צליל שלא קיים בערבית בכלל. בתעתיק, צ מסמנת ס מודגשת.
- **מה עושים:** אומרים ס, ת, ד או ז רגילים, ובאותו רגע מושכים את גב הלשון לאחור ומורידים מעט את הלסת. הסימן שהצלחתם: התנועה שאחרי העיצור נשמעת כהה ועמוקה (אָ במקום אַ).
- **זוגות מינימליים:** צֵיף (קיץ) ≠ סֵיף (חרב) · טִין (בוץ) ≠ תִין (תאנים)
- **דוגמאות:** צַבַּאח (בוקר), מַחַטַּה (תחנה), בַּעְד' (אחד את השני)

```yaml
id: emphatics
title: עיצורים מודגשים
arabic: ص ط ض ظ
checks:
  - {target: sˤ, heard: [s], severity: 2, feedback: "נהגתה כ־ס רגילה. משכו את גב הלשון לאחור: התנועה אחריה צריכה להישמע כהה."}
  - {target: sˤ, heard: [ts, t͡s], severity: 2, feedback: "נהגתה כמו צ עברית (ts). בתעתיק צ היא ס מודגשת, בלי t בהתחלה."}
  - {target: tˤ, heard: [t], severity: 2, feedback: "נהגתה כ־ת רגילה. ט ערבית מודגשת: גב הלשון לאחור, תנועה כהה."}
  - {target: dˤ, heard: [d], severity: 2, feedback: "נהגתה כ־ד רגילה. ד' מודגשת: גב הלשון לאחור, תנועה כהה."}
  - {target: ZH, heard: [z, ð, d], severity: 2, feedback: "נהגתה בלי הדגשה. ט' מודגשת: גב הלשון לאחור, תנועה כהה."}
```

### 3.4 ר מתגלגלת · מבטא חזק
- **למה זה קשה:** ר עברית נהגית בגרון, ובאוזן ערבית היא נשמעת כמו ע', שהיא עיצור אחר.
- **מה עושים:** ר ערבית נוצרת בקצה הלשון: נקישה אחת או גלגול מאחורי השיניים העליונות.
- **זוג מינימלי:** רֵים (צבייה) ≠ ע'ֵים (עננים)
- **דוגמאות:** כְּתִיר (הרבה), בֻּכְּרַה (מחר)

```yaml
id: r_tap
title: ר מתגלגלת
arabic: ر
checks:
  - {target: r, heard: [ʁ, ɣ, χ, x], severity: 2, feedback: "נהגתה גרונית, כמו ר עברית. ר ערבית מתגלגלת בקצה הלשון מאחורי השיניים."}
```

### 3.5 ע' היא ה־ר העברית שלכם · מבטא
- **למה זה קשה:** זה בעצם העיצור הקל ביותר לדוברי עברית, כי ע' היא כמעט בדיוק ה־ר העברית. הטעות הנפוצה היא לתקן יותר מדי: להגות אותה כ־ר מתגלגלת או כ־ג.
- **מה עושים:** אומרים ר עברית רגילה, מהגרון.
- **דוגמאות:** בַּשְתְע'ִל (אני עובד), ע'ַאלִי (יקר)

```yaml
id: ghain
title: ע' היא ה־ר העברית שלכם
arabic: غ
checks:
  - {target: ɣ, heard: [x, χ], severity: 1, feedback: "נהגתה בלי קול, כמו ח עברית. ע' קולית: אמרו ר עברית."}
  - {target: ɣ, heard: [r, ɾ], severity: 2, feedback: "נהגתה כ־ר מתגלגלת. ע' היא ה־ר הגרונית של העברית."}
  - {target: ɣ, heard: [g, ɡ], severity: 2, feedback: "נהגתה כ־ג. ע' היא חיכוך רציף, כמו ר עברית."}
```

### 3.6 ה נהגית תמיד · מבטא
- **למה זה קשה:** בעברית מדוברת ה נבלעת ברוב המקרים.
- **מה עושים:** נשיפה רכה וקצרה, גם באמצע מילה ולפני עיצור, ובלי שום חיכוך.
- **דוגמאות:** אַהְוֶה (קפה), פַאהֵם (מבין)

```yaml
id: h
title: ה נהגית תמיד
arabic: ه
checks:
  - {target: h, heard: ["_"], severity: 2, feedback: "נבלעה. ה נהגית תמיד, גם לפני עיצור."}
  - {target: h, heard: [ħ, χ, x], severity: 1, feedback: "נהגתה חזקה מדי. ה היא נשיפה רכה בלבד."}
```

### 3.7 ו = w, ב = b, פ = f · מבטא
- **למה זה קשה:** התעתיק העברי עצמו מטעה. ו נקראת v, ב רפה נקראת v, ופ דגושה נקראת p. בערבית אין v ואין p.
- **מה עושים:**
  - ו: מעגלים את השפתיים, w. וֵין נהגית wein ולא vein.
  - ב: סוגרים את השפתיים, גם בסוף מילה. שוֹבּ ולא שוֹב.
  - פ: תמיד f, גם בתחילת מילה. פִנְג'אן ולא פִּנְג'אן.
- **דוגמאות:** וֵין (איפה), אִלְחְסַאבּ (החשבון), פִנְג'אן (כוס קפה)

```yaml
id: w
title: ו היא w
arabic: و
checks:
  - {target: w, heard: [v, ʋ], severity: 2, feedback: "נהגתה v. בערבית אין v: עגלו את השפתיים, w."}
---
id: b
title: ב היא תמיד b
arabic: ب
checks:
  - {target: b, heard: [v, β], severity: 2, feedback: "נהגתה v. בערבית ב היא תמיד b, גם בסוף מילה."}
---
id: f
title: פ היא תמיד f
arabic: ف
checks:
  - {target: f, heard: [p], severity: 2, feedback: "נהגתה p. בערבית אין p: פ היא תמיד f."}
```

### 3.8 תנועה ארוכה · דיוק
- **למה זה קשה:** בעברית אין הבדל בין תנועה קצרה לארוכה. בערבית יש, והוא יכול לשנות משמעות.
- **מה עושים:** כשבתעתיק מופיעה א, י או ו אחרי התנועה, היא ארוכה ומחזיקים אותה בערך כפול.
- **זוג מינימלי:** עַלַם (דגל) ≠ עַאלַם (עולם)
- **דוגמאות:** כְּתִיר = ktiir, שוּף = shuuf (תראה)

הכלל משנה משמעות, אבל מקבל חומרה 1 כי מודל ההגאים מבחין באורך תנועה פחות טוב. ראו חלק 7.

```yaml
id: vowel_length
title: תנועה קצרה ותנועה ארוכה
checks:
  - {target: aː, heard: [a], severity: 1, feedback: "התנועה הארוכה נהגתה קצרה. החזיקו אותה בערך כפול."}
  - {target: iː, heard: [i], severity: 1, feedback: "התנועה הארוכה נהגתה קצרה. החזיקו אותה בערך כפול."}
  - {target: uː, heard: [u], severity: 1, feedback: "התנועה הארוכה נהגתה קצרה. החזיקו אותה בערך כפול."}
  - {target: eː, heard: [e, i], severity: 1, feedback: "התנועה הארוכה נהגתה קצרה. החזיקו אותה בערך כפול."}
  - {target: oː, heard: [o, u], severity: 1, feedback: "התנועה הארוכה נהגתה קצרה. החזיקו אותה בערך כפול."}
```

### 3.9 ג' ולא g · דיוק
- **מה עושים:** הוגים ג' כמו ב'ג'ינס', או ז' כמו ב'ז'קט'. שתיהן תקינות. ג רגילה (g) היא מבטא מצרי.
- **דוגמאות:** פִנְג'אן (כוס קפה), גַ'בַל או זַ'בַל (הר)

```yaml
id: jim
title: ג' ולא g
arabic: ج
checks:
  - {target: J, heard: [g, ɡ], severity: 1, feedback: "נהגתה g. בערבית פלסטינית ג' היא dʒ או ז'."}
```

### 3.10 שני עיצורים צמודים · דיוק
- **למה זה קשה:** בעברית מדוברת מוסיפים תנועה בין שני עיצורים שבאים ברצף (שווא נע), וכך גם בערבית: katiir במקום ktiir.
- **מה עושים:** מצמידים את שני העיצורים, בלי תנועה ביניהם. בתחילת משפט קשה להגות שווא, ולכן שם מותר שיישמע כמו e קצרה (צירה).
- **דוגמאות:** כְּתִיר = ktiir (לא katiir; בתחילת משפט גם ketiir), מְנִיח = mniiħ, בְּנְשוּף = bnʃuuf

ה־scorer בודק תנועה שהמודל שומע בבירור בין שני עיצורים של אותה מילה. הוא לא בודק את הצרור שפותח את המשפט (6.3 #16), ולא צירוף עם w או j, שהמעבר אליהם נשמע כמו תנועה גם אצל דוברים ילידיים.

```yaml
id: cluster
title: שני עיצורים צמודים
insertion:
  severity: 1
  min_peak: 0.5      # a vowel the model is at least this sure of ...
  min_frames: 2      # ... in at least this many frames (40 ms) between two consonants of one word
  score_cap: 60      # the second consonant scores at most this
  feedback: "נוספה תנועה בין שני העיצורים. הצמידו אותם, בלי תנועה ביניהם: ktiir ולא katiir. רק בתחילת משפט מותר e קצרה."
```

### 3.11 קובוץ ברור · דיוק
- **למה זה קשה:** את השווא מותר להחליש, ודוברי עברית מחלישים גם תנועות קצרות אחרות. אבל u (קובוץ) היא תנועה מובחנת מאוד: מֻחַאמִי (עורך דין) היא muħaami, ולא mħaami.
- **מה עושים:** הוגים את ה־u מלאה וברורה גם כשהיא קצרה, בלי להטעים אותה ובלי לבלוע אותה לשווא.
- **דוגמאות:** מֻחַאמִי = muħaami, בֻּכְּרַה = bukra, מֻשְכִּלֶה = muʃkile

זו התנועה הקצרה היחידה שה־scorer מסמן (ראו 6.3 #7), ורק אחרי עיצור באותה מילה, לא ו' החיבור.

```yaml
id: kubutz
title: קובוץ ברור
flag_vowels: [u]   # short u after a consonant is flagged, unlike the other short vowels (6.3 #7)
checks:
  - {target: u, heard: ["_"], severity: 1, feedback: "ה־u נבלעה. הגו אותה מלאה וברורה גם כשהיא קצרה: muħaami ולא mħaami."}
  - {target: u, heard: [e, i, ə], severity: 1, feedback: "ה־u נשמעה כמו e או שווא. u היא תנועה מובחנת: עגלו את השפתיים, muħaami."}
```

## 5. סימונים: הגאים מופשטים

ב־`phrases.py` כל אות שנהגית אחרת בעיר ובכפר נכתבת **כסימן מופשט** ולא כהגה ממומש. ה־scorer פורש כל סימן לכל המימושים התקינים שלו. כך נפתרות הכפילויות בשני הכיוונים:
- **אות אחת, כמה הגאים:** ق יכולה להיות ʔ, k או q.
- **הגה אחד, כמה אותיות:** ʔ יכול לבוא מ־ق או מ־ء, k יכול לבוא מ־ك או מ־ق כפרית, t יכול לבוא מ־ت או מ־ث עירונית.

```yaml
# archiphonemes: symbol in phrases.py -> realisations that are correct Palestinian speech
archiphonemes:
  Q:  {arabic: ق, urban: [ʔ],        rural: [k],    also_ok: [q],     optional: [g]}   # q: Druze / MSA. g: Bedouin, off by default
  K:  {arabic: ك, urban: [k],        rural: [k, tʃ], also_ok: []}
  TH: {arabic: ث, urban: [t, s],     rural: [θ],    also_ok: []}                       # s in learned words (ثقافة)
  DH: {arabic: ذ, urban: [d, z],     rural: [ð],    also_ok: []}                       # z in learned words
  ZH: {arabic: ظ, urban: [dˤ, zˤ],   rural: [ðˤ],   also_ok: []}
  J:  {arabic: ج, urban: [dʒ, ʒ],    rural: [dʒ],   also_ok: [ʒ]}
# plain phonemes are NOT expanded: ʔ written as ʔ (hamza) never accepts k; k written as k (from ك in urban-only words) uses K
dialects_enabled: [urban, rural]
optional_realisations_enabled: false   # true -> Bedouin g for Q
```

**דוגמאות לכתיבה ב־`phrases.py`:**

| עברית | כתיבה | יתקבל |
|---|---|---|
| קפה | `Q a h w e` | ʔahwe, kahwe, qahwe |
| כמה | `Q a d d eː ʃ` | ʔaddeeʃ, kaddeeʃ |
| כלב | `K a l b` | kalb, tʃalb |
| לב | `Q a l b` | ʔalb, kalb, qalb |
| הרבה | `K t iː r` (במקור ث) | ktiir, tʃtiir |
| שלוש | `TH l aː TH e` | tlaate, θlaaθe, וגם צירוף מעורב |
| שלום | `ʔ a h l a` (ء, לא ق) | ʔahla. ההגייה kahla **לא** מתקבלת |

**בניית המטרות:** לכל וריאנט במשפט ה־scorer בונה שתי מחרוזות מטרה, עירונית וכפרית. כל סימן מופשט ממומש במימוש הראשון שלו באותו ניב. כל מחרוזת עוברת יישור כפוי (forced alignment), ונבחרת זו שסבירותה גבוהה יותר. ערבוב ניבים בתוך משפט מטופל בשלב ההערכה, לפי סעיף 6.1.

## 6. היוריסטיקות להערכת הגה

### 6.1 מחלקות שקילות
לכל הגה מטרה שנבנה מסימן מופשט, ההסתברות היא **סכום ההסתברויות של כל המימושים התקינים** בחלון שלו, ולא רק של המימוש שנבחר ביישור.

לדוגמה, ב־`Q`: אם P(ʔ)=0.35 ו־P(k)=0.40, ה־GOP מחושב מול 0.75. התלמיד אמר מימוש תקין, גם אם ביישור נבחרה המחרוזת העירונית. הגה אחר מהמחלקה לא נחשב "מתחרה".

### 6.2 סף לשגיאה
הגה מסומן כשגוי רק אם מתקיימים שלושה תנאים:
1. הציון שלו נמוך מ־`flag_below`.
2. המתחרה החזק ביותר בחלון **לא** במחלקת השקילות של המטרה.
3. היחס בין המתחרה למטרה עובר את מרווח הביטחון של הזוג (`margin`).

לזוגות שהמודל מבלבל גם אצל דוברים ילידיים יש מרווח גדול יותר, כדי לא להעניש תלמיד על חולשה של המודל.

```yaml
scoring:
  flag_below: 50            # phoneme score 0..100
  unrelated_ratio: 0.65     # normalised edit distance of greedy decode vs target -> "different sentence?"
  accept_alt_min_post: 0.20 # an accepted realisation counts if its peak posterior >= this
  accepted_score_floor: 90  # score given to a phoneme realised as an accepted alternative
  deletion: {target_peak_max: 0.05, competitor_peak_max: 0.20}
  vowel_weight: 0.5
  severity_weight: {1: 1.0, 2: 1.5, 3: 2.0}
  sentence_score: "0.5 * weighted_phoneme_mean + 0.5 * mean(word_min)"   # a word scores as its weakest phoneme
  bands: {excellent: 85, almost: 60}                                    # below 60 = try again
  max_tips: 3
  # default margin: flag when log P(competitor) - log P(target) >= log(1.0), i.e. competitor at least as likely
  margin_default: 0.0
  margins:                  # stricter pairs (natural log ratio): competitor must exceed target by e^margin
    - {target: [sˤ, tˤ, dˤ, zˤ, ðˤ], heard: [s, t, d, z, ð], margin: 0.7}   # ~2x: emphasis is weak in the base model
    - {target: [h], heard: ["_"], margin: 0.7}                            # h is short and quiet, natives reduce it too
    - {target: [aː, iː, uː, eː, oː], heard: [a, i, u, e, o], margin: 1.1} # ~3x: length is unreliable from CTC posteriors
    - {target: [ħ], heard: [h], margin: 0.4}
```

## שינויים לעומת הקוד הנוכחי

הסעיפים האלה מתארים מה צריך לשנות ב־`app/rules.py`, ב־`app/scorer.py` וב־`app/phrases.py` כדי שיתאימו למסמך:

1. **כלל ק עירונית (`qaf`) מבוטל כשגיאה.** בגלל ש־kahwe תקינה בכפר, ق הופכת למחלקת שקילות `Q`.
2. **סימנים מופשטים חדשים:** `K`, `TH`, `DH`, `ZH` ו־`J` מצטרפים ל־`Q`. הפרופיל הבודד מוחלף ב־`dialects_enabled: [urban, rural]`.
3. **ה־GOP מחושב מול סכום ההסתברויות של מחלקת השקילות** (סעיף 6.1), במקום ה"החלפה בדיעבד" הנוכחית, שבה ציון ההגה פשוט מוגבה ל־90.
4. **מרווחים לפי זוג** (סעיף 6.2) ו**מקרים מיוחדים 1–8** הם חדשים.
5. **תעתיק:** צ' (tʃ), ת' (θ) ו־ד״ (ð) נוספים. ד' נשארת ד מודגשת (ض).
