# טיוטת העתיד של פעלי שלב א' — לבדיקה

הטבלה מציגה את צורות העתיד של כל פועל משלב א' שחסרה לו לפחות צורה אחת במאגר (LEX). ✓ = כבר במאגר ונבדקה. ✎ = טיוטה שנבנתה לפי הכלל, וצריך לבדוק אותה. אחרי הבדיקה, הצורות הנכונות עוברות ל־LEX (`app/workbook.py`) ונמחקות מ־`app/future_draft.py`. פועל שכל שמונה הצורות שלו נמצאות ב־LEX מגיע לתלמידים במשחק "בונים פועל עם איתן". עד אז רק מורים רואים אותו, עם התווית טיוטה.

**כבר מוכנים לתלמידים (11):** שאל (يسأل), ישב (يقعد), בא (يجي), דיבר (يحكي), ביקר (يزور), ראה (يشوف), שתה (يشرب), יצא ועלה (يطلع), שמע (يسمع), אכל צהריים (يتغدّى), שיחק (يلعب)

מה לבדוק בכל ✎: הכתיב בערבית, התעתיק (בעיקר התנועה של התחילית: יִ / יֻ / יְ) וההגייה. השמטת התנועה ב־ـي/ـו (למשל תֹאכְּלִי) נבנתה רק במקומות שבהם היא כבר מופיעה במאגר.
